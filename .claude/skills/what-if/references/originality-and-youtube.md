# Originality, sources and YouTube

## Original work

Before scripting, search YouTube for the exact What If question and a few close phrasings. If a video already uses the same central angle, change the scenario, mechanism or storytelling lens. Do not copy another creator's script, title, scene order, characters, thumbnail, music or sound design.

Use anime as a broad visual medium, not as a request to imitate a named show, studio or living artist. Make original characters, designs, compositions and captions.

## Science sources

Keep a source list in `out/<slug>/sources.md`. Use primary or authoritative sources for claims and numbers. Mention key sources in the video description. Make assumptions and speculative outcomes explicit; keep confirmed science separate from visual storytelling.

## Assets and rights

Track licenses for fonts, images, music and effects. Prefer original code-drawn visuals and original sound. A user-provided file does not automatically have publishing rights. Do not promise copyright clearance or monetization.

## YouTube export references

Check the latest official pages before export because platform requirements can change:

- [Recommended upload encoding settings](https://support.google.com/youtube/answer/1722171) — MP4/H.264, progressive scan, frame-rate, audio and color guidance.
- [Understand three-minute YouTube Shorts](https://support.google.com/youtube/answer/15424877) — current duration and aspect-ratio eligibility.
- [Shorts upload tips](https://support.google.com/youtube/answer/12921536) — upload workflow and presentation advice.

Do not describe a file as ready if its codec, frame rate, sound, aspect ratio, source list or rights questions have not been checked. A technically ready file has not been uploaded until the user uploads it.
